# 🌍 TrunfoWorld

**TrunfoWorld** é uma recriação em **C** do clássico jogo de cartas **Super Trunfo – Países**, jogado diretamente no **terminal**.  
Prepare-se para duelos épicos de atributos e descubra quem domina o mundo dos países! 🃏

---

## ✨ Funcionalidades
- 🌍 Baralho com países e seus atributos (população, área, PIB, etc.)
- 🖥️ Interface no terminal com cores e ASCII art
- 🎲 Mecânica clássica de comparação de atributos
- 📊 Estatísticas de vitórias e derrotas
- 🔧 Fácil de expandir: crie seu próprio baralho!
